# Security Policy

## Scope

This repository contains documentation and instructions for an AI-assisted product-page UX audit. It is not intended to collect credentials, payment information, or private customer data.

## Reporting a concern

Please do not publish sensitive information, credentials, or private customer data in a public issue.

If you identify a security or privacy concern involving this project, contact the repository maintainer privately through the contact method on their GitHub profile. Include:

- A short description of the concern.
- The affected file or feature.
- Steps to reproduce the issue, if applicable.
- Any relevant impact or mitigation suggestions.

Please allow time for the maintainer to review the report before publicly disclosing details.
