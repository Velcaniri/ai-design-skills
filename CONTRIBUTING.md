# Contributing

Thank you for considering a contribution to Product Page UX Audit.

## Ways to contribute

- Report unclear, incorrect, or incomplete audit guidance.
- Suggest additional product-page UX checks.
- Improve examples and documentation.
- Clarify recommendations or add useful validation guidance.
- Report formatting or compatibility problems with the skill.

## Before opening an issue

1. Search existing issues to see whether the topic has already been raised.
2. Explain the problem or proposed improvement clearly.
3. Include a relevant example where possible.
4. For UX recommendations, explain the user problem and the reasoning behind the proposed change.

## Pull request guidelines

1. Keep changes focused and reasonably small.
2. Update the README or examples when behavior or guidance changes.
3. Preserve the skill's central principle: recommendations should be specific, contextual, and evidence-based.
4. Do not add checklist items just to increase the number of findings.
5. Explain what changed and why in the pull-request description.

## Writing guidelines

- Prefer clear, direct language.
- Explain the user impact of a recommendation.
- Distinguish usability issues from subjective visual preferences.
- Avoid presenting optional patterns as universal rules.
- Do not claim that a design issue is verified when the supplied screenshot or prototype cannot establish it.

By contributing, you agree that your contributions will be made available under the repository's MIT License.
