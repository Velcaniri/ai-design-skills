# Web Design

Help websites communicate clearly, work across screens, and support visitor goals. Combine information architecture, content, hierarchy, responsive layout, interaction, and implementation constraints.

## Workflow

1. Establish purpose, audience, visitor tasks, content, brand, and success criteria.
2. Map page or journey structure before polishing individual sections.
3. Set a responsive grid, type scale, spacing, color, and component rules.
4. Make the first viewport identify the site and its next useful action; keep deeper content scannable.
5. Specify navigation, links, forms, interactive states, loading, and error feedback.
6. Review narrow and wide screens, keyboard flow, zoom, content length, image crops, and motion preferences.

## Website review

Check that visitors can tell where they are, what the site offers, and what they can do next. Use familiar web conventions when they help orientation; explain departures. Keep labels and actions close to the content they explain. Ensure hierarchy survives reflow and essential content is not available only through hover, animation, or 3D. Use clear link/button semantics, visible focus, legible type, sufficient contrast, and useful fallbacks for rich media.

A visual pattern should earn its complexity. Review mobile loading and performance, reduced-motion settings, and browser navigation. Scroll-led layouts must preserve ordinary scroll expectations, show progress, and provide a clear route back or out.

For critique, report **Finding / Evidence / Visitor impact / Change / Priority** and mark unverified behavior. For a redesign brief, include page structure, responsive behavior, key states, accessibility, and content needs. Distinguish confirmed usability issues from aesthetic preferences.

Use `cinematic-web-interactions` for immersive scene transitions and `motion-design` when motion is central.
