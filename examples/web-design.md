# Example: Web Design

## Scenario

A small repair shop needs a responsive website that helps visitors find services, hours, and a way to request an appointment.

## Example page structure

1. **Header:** Shop name, Services, Hours & location, and a clear “Request an appointment” link.
2. **Hero:** A plain-language headline, one sentence describing the shop, and the appointment action.
3. **Services:** Three service groups with short descriptions and starting-price context where confirmed.
4. **Practical details:** Hours, address, transit or parking notes, and phone number.
5. **Footer:** Repeat essential contact details and privacy information.

## Review example

On narrow screens, the appointment button wraps between the headline and supporting copy. The primary action becomes hard to scan.

**Change:** Let the hero stack in a clear order, keep the button full-width where appropriate, and maintain spacing between it and the copy. Check keyboard order and ensure no important information appears only on hover.

Before adding a motion-heavy hero, make sure the page still answers the visitor's basic questions quickly.
