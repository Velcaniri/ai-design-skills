# Example: Design Foundations

## Brief

Create a square event graphic for a neighborhood night market. The event name, date, location, and “free entry” message must be readable in a social feed.

## Worked direction

- Make the event name the first visual stop and the date the second.
- Group date, time, and location as one information unit.
- Use one strong image or illustration as the focal point, leaving space around the copy.
- Align the event details to a shared edge and use a restrained type and color system.
- Keep “free entry” distinct without letting it compete with the event name.
- Check the design at phone size and in a square crop.

## Review example

**Finding:** The date and location sit far apart and use unrelated styles.

**Why it matters:** People may read the date without finding where the event is.

**Change:** Put date, time, and location together with one consistent label style.

This example uses hierarchy, proximity, alignment, contrast, and negative space together rather than treating them as separate scoring rules.
